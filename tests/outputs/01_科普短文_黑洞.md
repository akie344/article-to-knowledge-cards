# 黑洞 · 知识卡片（6 张）

### 黑洞的定义

**核心知识：** 黑洞是引力极强、连光都无法逃脱的天体。

**简明解释：** 黑洞的引力大到连以光速运动的光都无法逃逸，因此它本身不发光，也无法被直接看见。

**例子或自测问题：** 为什么黑洞本身无法被直接看见？
参考答案：因为它的引力强到连光都无法逃脱。

### 黑洞的形成

**核心知识：** 黑洞由大质量恒星在生命末期坍缩形成。

**简明解释：** 恒星核燃料耗尽后，若质量足够大，会在自身引力作用下向内坍缩，最终形成黑洞。

**例子或自测问题：** 黑洞是由什么天体演化形成的？
参考答案：大质量恒星在生命末期坍缩形成。

### 事件视界

**核心知识：** 事件视界是黑洞的边界，一旦越过，任何物质和光都无法出来，外界也观察不到其内部。

**简明解释：** 事件视界以内是“有去无回”的区域，外界无法获得视界内部的任何信息，因此黑洞内部情况只能间接推测。

**例子或自测问题：** 如果把一颗恒星推过事件视界，它将永久消失，外界再也观测不到它。

### 奇点

**核心知识：** 黑洞中心是一个密度无限大的点，叫做奇点。

**简明解释：** 奇点位于事件视界内部，黑洞的全部质量都集中在这里，密度趋于无穷大。

**例子或自测问题：** 黑洞中心密度无限大的点叫什么？
参考答案：奇点。

### 吸积盘与观测方法

**核心知识：** 黑洞吸引气体尘埃形成高速旋转的吸积盘，因摩擦生热发出 X 射线，科学家据此间接发现黑洞。

**简明解释：** 物质在落向黑洞的过程中高速旋转、相互摩擦产生高温并辐射出 X 射线；因为黑洞本身不可见，科学家主要通过探测这种 X 射线来间接确认黑洞的存在。

**例子或自测问题：** 天文学家观测到某个致密天体周围有强烈 X 射线源，进一步确认那里存在黑洞。

### 黑洞的分类

**核心知识：** 黑洞按质量可分为恒星级黑洞和超大质量黑洞等类型，超大质量黑洞通常位于星系中心，质量可达太阳的百万倍以上。

**简明解释：** 恒星级黑洞由单个大质量恒星坍缩形成，质量相对较小；超大质量黑洞位于星系中心，质量巨大，可达太阳质量的百万倍以上。

**例子或自测问题：** 超大质量黑洞通常位于哪里，质量大约是太阳的多少倍？
参考答案：通常位于星系中心，质量可达太阳的百万倍以上。
