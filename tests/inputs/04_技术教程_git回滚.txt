Git 回滚提交的三种常用方法
============================

一、git reset 软回退（保留改动）
git reset --soft HEAD~1 可以把 HEAD 指向上一次提交，但暂存区和工作区的内容都保留。适合提交后发现少加了文件，想重新提交的情况。

二、git reset 硬回退（丢弃改动）
git reset --hard HEAD~1 会把 HEAD、暂存区和工作区全部回到上一次提交的状态，本地未提交的改动也会被丢弃。注意：硬回退后原来的提交记录就没了，操作前要确认没有需要保留的改动。

三、git revert 反做提交（保留历史）
git revert HEAD 会生成一个新的提交，把上一次提交的改动反过来撤销，但保留完整的历史记录。适合已经推送到远程仓库的提交，因为不会改写历史，团队协作时更安全。

总结：本地未推送的提交用 reset（软回退保留改动、硬回退丢弃改动），已经推送到远程的提交用 revert，避免影响其他人。
