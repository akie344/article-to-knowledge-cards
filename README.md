# make-knowledge-cards

把文章一键转换成 5～8 张结构化知识卡片的开源 Agent Skill。

## 1. 项目解决什么问题

读文章、记笔记时，最常见的问题是：**抓不住重点、记了等于没记、复习时还要重读全文**。手工把一篇材料拆成知识点既耗时又容易遗漏；让 AI 直接"总结要点"又常常得到冗长、重复甚至编造的内容。

本项目提供一个纯指令型的 Agent Skill：把**用户粘贴的文章或本地 Markdown / TXT 文件**整理成一组高质量知识卡片，每张卡片只承载一个真正重要的知识点，信息全部忠于原文，可快速用于学习、复习与分享。

## 2. 主要功能

**输入**
- 直接粘贴的文章、笔记、讲义等纯文本
- 本地 `.md` / `.txt` 文件（自动完整读取全文）

**输出**
- 一组 Markdown 知识卡片（默认 5～8 张，信息不足时不强行凑数，知识点过多时按重要性取前 8 张并注明）
- 每张卡片固定四个字段：
  - **标题**：点明知识点的短标题
  - **核心知识**：一句话概括的唯一知识点
  - **简明解释**：2～4 句把知识点讲清楚
  - **例子或自测问题**：一个具体例子，或一个可用原文作答的自测题（附参考答案）

**质量保证机制**
- 一张卡片只讲一个知识点，重复内容自动合并删除
- 严禁编造原文没有的信息，保留原文限定词与前提条件
- 卡片语言与原文一致（如英文小说输出英文卡片，用户指定时可输出中文）

**暂不支持**：网页抓取、PDF 及其它格式文档、Anki 导出、图形界面。

## 3. 安装方法

本 Skill 遵循 Agent Skills 开放标准（`SKILL.md` + `agents/openai.yaml`），结构兼容 Cursor、VS Code、GitHub Copilot、Claude Code 等支持该标准的 Agent 工具。

1. 将 `skills/make-knowledge-cards/` 整个文件夹复制到你的 Agent 的 skills 目录，例如：
   - `~/.agent/skills/`（个人级）
   - `workspace/.user_skills/`（工作区级）
   - 或平台指定的 skills 目录（具体路径以平台文档为准）
2. 重启或刷新 Agent，使其重新扫描 skills 目录。
3. 无需任何依赖：本 Skill 为纯指令型，**不含脚本、不需要安装 Python 包或配置 API**，复制即用。

## 4. 使用方法

安装后直接向 Agent 提出要求即可，例如：

- “把这篇文章整理成知识卡片”
- “把 `notes.md` 转成学习卡片”
- “帮我拆解下面这段文字的知识点”（随后粘贴文本）
- “把这份英文资料做成知识卡片，输出中文”

Agent 会按 `SKILL.md` 定义的工作流程自动执行：

```
完整读取输入 → 通读理解主旨 → 提取候选知识点 → 筛选去重 → 生成卡片 → 自检
```

## 5. 输入输出示例

**输入（粘贴文本）：**

> 光合作用是植物利用光能，把二氧化碳和水合成有机物并释放氧气的过程。它包括光反应和暗反应两个阶段。光反应发生在叶绿体的类囊体薄膜上，需要光照，把水分解成氧气，并产生 ATP 和 NADPH。暗反应发生在叶绿体基质中，不需要光，利用 ATP 和 NADPH 把二氧化碳固定并还原成有机物。影响光合作用的因素主要有光照强度、温度和二氧化碳浓度。

**输出（知识卡片，节选）：**

```markdown
# 光合作用 · 知识卡片（4 张）

### 光合作用定义

**核心知识：** 光合作用是植物利用光能将二氧化碳和水合成有机物并释放氧气的过程。

**简明解释：** 光合作用需要光能作为能量来源，原料是二氧化碳和水，产物是有机物和氧气，是植物制造养料和氧气的基础途径。

**例子或自测问题：** 光合作用的原料和产物分别是什么？
参考答案：原料是二氧化碳和水，产物是有机物和氧气。
```

## 测试

`tests/` 目录包含真实测试样例：

| 测试类型 | 输入 | 输出 |
| --- | --- | --- |
| 科普短文（黑洞，6 个知识点） | `tests/inputs/01_科普短文_黑洞.txt` | `tests/outputs/01_科普短文_黑洞.md` |
| 长文档（学习方法，10 节→取前 8 张） | `tests/inputs/02_长文档_学习方法.md` | `tests/outputs/02_长文档_学习方法.md` |
| 信息稀少短文（3 个知识点→不强凑） | `tests/inputs/03_信息稀少短文_冰.txt` | `tests/outputs/03_信息稀少短文_冰.md` |
| 技术教程（Git 回滚，4 个知识点） | `tests/inputs/04_技术教程_git回滚.txt` | `tests/outputs/04_技术教程_git回滚.md` |
