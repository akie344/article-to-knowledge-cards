# Make Knowledge Cards

## Overview

把用户粘贴的文章或本地 Markdown / TXT 文件转换成一组结构化知识卡片，帮助快速掌握一篇材料的核心知识点。

输出 5～8 张卡片；每张卡片只讲一个知识点，包含四个固定字段：标题、核心知识、简明解释、例子或自测问题。

## 输入与边界

**支持的输入：**
- 用户直接粘贴的文章、笔记、讲义等纯文本
- 本地 `.md` / `.txt` 文件（先完整读取文件内容，再按本文档流程处理）

**不支持的输入（遇到时明确告知用户，不强行处理）：**
- 网页链接（不抓取网页）
- PDF 及其他格式文档
- Anki 卡片格式导出
- 图形界面 / 可视化卡片

如果用户给的输入不在支持范围内，说明原因并询问是否改为粘贴文本或提供 .md/.txt 文件。

## 工作流程

按顺序执行以下步骤：

1. **完整读取输入**：粘贴文本全部读入；文件则先读取全文（长文件分段读完，不以摘要代替）。
2. **通读理解**：把握文章主旨、结构、论证或叙述主线，识别作者真正想传递的知识点，忽略铺垫、修辞、客套和与主旨无关的细节。
3. **提取候选知识点**：列出所有候选知识点，每个候选点用一句话概括。
4. **筛选与去重**：
   - 只保留“真正重要”的知识点（去掉琐碎信息、与主旨无关的举例说明性细节）
   - 合并表达同一知识点的重复段落，删除完全重复的内容
   - 确保每张卡片只对应一个知识点；若一个候选点含多个子知识点，拆分或合并到邻近卡片
5. **生成卡片**：按下方“卡片模板”为每个知识点生成一张卡片。
6. **自检**：对照“质量规则”逐条检查，不符合则修改后再输出。

## 卡片模板

每一张卡片严格使用以下结构（输出 Markdown）：

```markdown
### 卡片标题

**核心知识：** 一句话概括本卡片的唯一知识点。

**简明解释：** 2～4 句，用原文的要点把知识点讲清楚；语言直白，不堆砌术语。

**例子或自测问题：** 给出一个具体例子，或提出一个自测问题（二选一，选择对理解该知识点更有帮助的那一种；也可两者都给）。
```

模板要点：
- 标题要短、能点明知识点（不超过 15 字为宜）
- “核心知识”必须是一句话，是本卡片的唯一知识点
- “简明解释”是对该知识点的展开说明，内容必须能在原文中找到依据
- “例子或自测问题”中的例子必须来自原文或由原文直接推导；自测问题必须能用原文内容作答，并在卡片后附参考答案（放在问题下方的“参考答案”一行）

## 质量规则（必须遵守）

1. **一张卡片只讲一个知识点**：宁拆不混；一个知识点跨多个段落时合并进同一张卡片。
2. **只保留真正重要的知识**：去掉铺垫、客套、重复和与主旨无关的细节。
3. **删除重复内容**：同一信息在原文中出现多次时，只保留一次。
4. **禁止编造**：卡片中所有信息必须来自原文；不得补充原文没有的事实、数字、结论或例子。原文未明确的内容不得自行推断为事实。
5. **数量弹性**：默认输出 5～8 张卡片；若原文信息不足 5 个知识点，输出实际数量的卡片（最少 1 张），不要强行凑数；若原文知识点超过 8 个，按重要性排序取前 8 个，并在输出末尾注明“原文知识点较多，已按重要性选取前 8 个”。重要性优先参考：与文章主旨直接相关的核心概念、方法论、结论 > 支撑性细节与示例 > 背景铺垫。
6. **忠实原文**：卡片总量与原文信息量匹配，不夸大、不缩减；保留原文的限定词（如“可能”“部分”“据统计”）与前提条件，避免绝对化。
7. **语言一致**：卡片使用与原文相同的语言输出（除非用户另有指定）。

## 输出格式

- 先输出一行总标题（`# 文章名 · 知识卡片（N 张）`，文章名取自原文标题或概括主题）。
- 再按知识点重要程度从高到低依次输出各卡片。
- 卡片之间用空行分隔。
- 若因信息不足导致卡片数少于 5 张，在末尾加一行说明：“原文有效知识点不足 5 个，未强行扩充。”

## 示例

**输入：**

> 光合作用是植物利用光能，把二氧化碳和水合成有机物并释放氧气的过程。它包括光反应和暗反应两个阶段。光反应发生在叶绿体的类囊体薄膜上，需要光照，把水分解成氧气，并产生 ATP 和 NADPH。暗反应发生在叶绿体基质中，不需要光，利用 ATP 和 NADPH 把二氧化碳固定并还原成有机物。影响光合作用的因素主要有光照强度、温度和二氧化碳浓度。

**输出：**

```markdown
# 光合作用 · 知识卡片（4 张）

### 光合作用定义

**核心知识：** 光合作用是植物利用光能将二氧化碳和水合成有机物并释放氧气的过程。

**简明解释：** 光合作用需要光能作为能量来源，原料是二氧化碳和水，产物是有机物和氧气，是植物制造养料和氧气的基础途径。

**例子或自测问题：** 光合作用的原料和产物分别是什么？
参考答案：原料是二氧化碳和水，产物是有机物和氧气。

### 光反应阶段

**核心知识：** 光反应发生在叶绿体类囊体薄膜上，需要光照，分解水产生氧气，并生成 ATP 和 NADPH。

**简明解释：** 光反应依赖光照，位置在类囊体薄膜；它将水分解为氧气，同时把光能转化为化学能储存在 ATP 和 NADPH 中，供暗反应使用。

**例子或自测问题：** 晴天光照充足时，光反应能快速产生大量 ATP 和 NADPH，为后续暗反应提供能量和还原力。

### 暗反应阶段

**核心知识：** 暗反应发生在叶绿体基质中，不需要光，利用 ATP 和 NADPH 固定二氧化碳并还原为有机物。

**简明解释：** 暗反应在叶绿体基质中进行，不需要光照，但需要光反应提供的 ATP 和 NADPH；它将二氧化碳固定并还原成有机物，是碳进入有机物的环节。

**例子或自测问题：** 暗反应发生在哪里，需要光吗？
参考答案：发生在叶绿体基质中，不需要光。

### 影响光合作用的因素

**核心知识：** 光照强度、温度和二氧化碳浓度是影响光合作用的主要因素。

**简明解释：** 这三个因素分别影响光反应所需的能量供应、酶活性以及暗反应的原料供应，任一因素受限都会降低光合作用速率。

**例子或自测问题：** 原文提到影响光合作用的因素有哪些？
参考答案：光照强度、温度和二氧化碳浓度。

原文有效知识点不足 5 个，未强行扩充。
```
